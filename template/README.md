# Promo videos

Motion-graphics promo films built with [Remotion](https://www.remotion.dev) (React → MP4) and cut
to an ElevenLabs v4 voiceover. Scaffolded by the `promo-video` Claude Code skill; see `brief.md`
for the audience, message, sources and status.

> **Licence.** Remotion is free only for individuals and companies with up to 3 employees. Larger
> companies need a [Remotion Company License](https://www.remotion.pro/license) before commercial use.

## Commands

```bash
npm ci                          # once (Node 22.18+)
npm run studio                  # live preview, scrub the timeline
npm run check                   # lint script, cues, props, assets, length
npm run script -- <cut>         # ElevenLabs-ready text + voice settings
npm run vo:guide                # robotic guide voice (macOS) for previews
npm run vo:import -- <cut> <file.mp3>   # normalise a take to −16 LUFS → public/voiceover/<cut>.mp3
npm run sync [-- <cut>]         # whisper.cpp alignment → src/timings/<cut>.json (language: VOICE.language)
npm run render [-- <cut>] [--draft]     # → out/<slug>-<cut>.mp4
npm run qa -- <cut> [--draft]   # contact sheets + loudness/alignment report in .qa/<cut>/
```

## How it fits together

- `src/script.ts` — the single source of truth: each cut is a list of sections (spoken text with
  ElevenLabs tags, a scene, scene props with spoken cues).
- `src/brand.ts` — colours, fonts, logos, names, app chrome.
- `src/scenes/` — the scene library (`catalog.ts` lists them); `custom/` for product-specific ones.
- `src/timings/` — generated by `npm run sync`; the picture follows the voice.
- `src/timeline.ts` — places the take on the timeline: a section's `hold` / `holdAfter` /
  `minSeconds` splits the one take in a pause and inserts silence, so a scene gets the time its
  picture needs (no re-recording, no re-sync).
- `src/footage.ts` — swap any scene for a real clip; optional music bed.

Re-voicing: generate `npm run script -- <cut>` in elevenlabs.io (or via a connector), download → `vo:import` → `sync` → `render`. Changing words: edit `src/script.ts`,
`check`, re-record (or `vo:guide`), `sync`, `render`.
